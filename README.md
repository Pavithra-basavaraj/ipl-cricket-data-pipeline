# IPL Cricket Data Engineering Pipeline

An end-to-end data engineering project that ingests IPL cricket data from a REST API and transforms it into analytics-ready datasets.

## Tech Stack

- Python
- REST API / RapidAPI
- Microsoft Fabric
- PySpark
- MySQL
- Power BI
- Git / GitHub
